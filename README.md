# ExpenseTracker

An intuitive and secure Expense Tracker Application built using the MERN stack (MongoDB, Express.js, React, Node.js).  
This app allows users to sign up, sign in, manage their income and expenses, and view their financial summary — all in one place.  
Users can also download a detailed report of their transactions.

## 🚀 Features

- 🔐 User Authentication
  - Sign up and log in to your personal account
  - Secure password handling and JWT-based authentication

- 📊 Dashboard Overview
  - Displays Total Balance, Total Income, and Total Expense
  - Quick financial snapshot of your account

- 💸 Income & Expense Management
  - Add, edit, or delete income and expense records
  - View categorized and timestamped entries

- 📑 Report Download
  - Export full transaction history (income or expense) as a report file
